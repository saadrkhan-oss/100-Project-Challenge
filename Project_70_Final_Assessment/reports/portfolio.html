VULN-001: SQL Injection (Login)

CVSS: 9.8 CRITICAL

OWASP: A03:2021 – Injection

CWE: CWE-89

Evidence: POST /login username=admin' OR '1'='1 → 200 OK + user data

Impact: Full database compromise (user credentials, PII)

Fix: Use parameterized queries (PDO/MySQLi)

VULN-002: Reflected XSS (Search)

CVSS: 6.1 HIGH

OWASP: A03:2021 – Injection

CWE: CWE-79

Evidence: GET /search?q= → reflected in HTML

Impact: Session hijacking, phishing, defacement

Fix: Output encoding (htmlspecialchars), CSP header

VULN-003: SSRF (Image Fetch)

CVSS: 8.6 HIGH

OWASP: A10:2021 – SSRF

CWE: CWE-918

Evidence: GET /fetch?url=http://169.254.169.254/ → AWS metadata returned

Impact: Cloud credential theft, internal network scan

Fix: Whitelist URLs, block private IP ranges

VULN-004: XXE (XML Upload)

CVSS: 9.1 CRITICAL

OWASP: A05:2021 – Security Misconfiguration

CWE: CWE-611

Evidence: POST /upload XML with → file content

Impact: File disclosure, SSRF, RCE potential

Fix: Disable external entities (defusedxml)

VULN-005: IDOR (User Profile)

CVSS: 8.1 HIGH

OWASP: A01:2021 – Broken Access Control

CWE: CWE-639

Evidence: GET /api/users/2 with user1's token → user2's data

Impact: Horizontal privilege escalation (all users' data)

Fix: Enforce ownership check (user_id == token.sub)

VULN-006: Broken Authentication (Weak JWT)

CVSS: 9.1 CRITICAL

OWASP: A07:2021 – Identification and Authentication Failures

CWE: CWE-798

Evidence: JWT secret 'secret123' cracked in <1s (hashcat)

Impact: Full account takeover (forge any token)

Fix: Strong random secret (32+ bytes), rotate regularly

VULN-007: Security Misconfiguration (Debug)

CVSS: 7.5 HIGH

OWASP: A05:2021 – Security Misconfiguration

CWE: CWE-489

Evidence: GET /debug → Werkzeug debugger with interactive shell

Impact: RCE via debugger (PIN bypass)

Fix: Disable debug=True in production
